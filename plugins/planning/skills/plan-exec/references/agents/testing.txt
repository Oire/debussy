Lens: tests.

Find new or changed code paths without tests, and error paths nobody exercises. Spend most of your effort on tests that exist but prove nothing:
- they pass no matter what the code does
- they assert a hardcoded value rather than the output
- they verify the mock instead of the code using it
- assertions sit inside a condition that never runs
- errors or exceptions are swallowed inside the test
- a failing case has been commented out or skipped

Also flag tests that depend on each other's state or on run order.
