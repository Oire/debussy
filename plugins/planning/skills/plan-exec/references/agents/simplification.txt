Lens: code that works but is more complicated than it needs to be.

Look for:
- layers that only pass calls through
- a factory, interface, or plugin point with a single implementation and no second one in sight
- configuration objects for two or three options
- extension points nothing extends
- fallbacks that never trigger, or that hide a failure that should surface
- old and new code paths living side by side when the old one has no callers
- caching and pooling for work that happens rarely

For each finding, say what the simpler version looks like and roughly how much work it is (trivial, small, medium, large). Complexity that the problem genuinely needs, or that matches an established pattern in the codebase, is not a finding.
