Lens: consistency with the project's own conventions.

Take the conventions from CLAUDE.md, any style guides it points to, and the code around the change, not from general taste. Then check the new code against them: naming, file and module layout, import order, comment density, error handling, and logging. Also look for dead code, duplicated logic, magic values, and a function doing several jobs at different levels of abstraction.

Cite the convention each finding breaks (a CLAUDE.md line, or a file that does it the project's way). A preference with no convention behind it is not a finding.
